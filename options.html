About ClearView

ClearView

Smart Popup Cleaner · v1.0.0

ClearView is an open-source Chromium extension that intelligently identifies and removes intrusive anti-adblock overlays, newsletter modals, and promotional popups — while preserving legitimate dialogs like login screens, cookie consent, and payment forms.

Permissions Explained

storage
Save your settings and diagnostic log locally in the browser.
activeTab
Access the current tab to read its URL for popup display and domain checks.
scripting
Send messages to the content script running in the active tab.
tabs
Query tab URL to determine if a page is restricted (chrome://, edge://, etc.).
host_permissions: <all_urls>
Inject the content script into all HTTP/HTTPS pages so detection can run automatically.

Privacy Commitment

  • No data is transmitted to any external server.
  • No browsing history, page content, or credentials are recorded.
  • All settings are stored locally in chrome.storage.local.
  • Diagnostic logs are bounded, local, and user-clearable.
